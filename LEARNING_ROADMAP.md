# Six-Semester Learning Roadmap

## Semester 1 — Fundamentals
- Learn Python basics and problem-solving.
- Practise Linux commands and shell scripting.
- Understand Git and GitHub workflows.

## Semester 2 — Programming Practice
- Improve Python programming.
- Learn data structures and basic algorithms.
- Build small command-line projects.

## Semester 3 — Web and APIs
- Learn HTML, CSS, and JavaScript fundamentals.
- Understand REST APIs and JSON.
- Build and document a simple API-based project.

## Semester 4 — Development Skills
- Learn database fundamentals and SQL.
- Practise testing and debugging.
- Build a full-stack beginner project.

## Semester 5 — Specialisation
- Explore areas such as backend development, AI, or cybersecurity.
- Contribute to suitable open-source projects.
- Improve project documentation.

## Semester 6 — Portfolio and Career Preparation
- Refine and deploy selected projects.
- Prepare a technical resume.
- Practise interview and problem-solving skills.

This roadmap is flexible and will be updated as I progress.
